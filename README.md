# ❤️ Love Letter Website — Version 2

Premium romantic static site built with HTML, CSS and JavaScript.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload everything in this folder to the repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/(root)`.
6. Save and wait for the Pages URL.
7. Send her the URL. ❤️

The included `.github/workflows/pages.yml` also supports GitHub's Pages workflow deployment if you prefer Actions.

## Customize

Edit `index.html` to change names, quotes and apology text.

Your two uploaded photos are already in:
- `images/memory-1.jpg`
- `images/memory-2.jpg`

If you add more private photos, remember that a public GitHub Pages site makes them accessible to anyone with the link.
